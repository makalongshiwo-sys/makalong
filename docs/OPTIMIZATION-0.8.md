# 0.8 原生优化

## 本次修复

- 网络：取消前台任务同时异步关闭对应连接，不在主线程等待断网；取消队列任务立即移出；同源校时失败退避 15 秒，避免六周期串行反复超时。限制 8 秒连接、10 秒读取与 2.5MB 响应。保留 HTTPS 来源白名单、不跟随重定向。
- 行情：按请求开始时的来源时间决定闭合，避免跨收盘边界的迟到回包把候选 OHLC 用作确认。报价失败保留最后来源时间并标识旧数据。
- 离线：研报与 ETF 优先显示已验证本机/随包资料，再检查网络。损坏缓存跳过并回退随包资产。ETF 严格检查日期、非有限数字、空行、重复基金、完整披露的分基金与总额；非法日历日期拒绝解析。
- 生命周期：暂停时取消前台请求；恢复时重新建立页面并刷新。记住币种、周期、ETF 日期范围；旋转时保存研究详情、研究周期、分页和滚动位置。
- 图表：多指操作结束不触发详情点击，抬指重置拖动坐标，历史窗口在新 K 线加入后保持位置，复用六条绘图 Path；指标不跨数据断档连接。增加键盘操作和按钮无障碍角色；重新分配指标区域，避免大字体下 RSI 刻度重叠，缩短最新线按钮文字。
- 耗电：前台暂停后停止报价、图表和资料网络任务；让系统决定刷新率。报价仍为约 3 秒 HTTPS 轮询，图表约 15 秒，ETF 披露约 5 分钟。
- 通知：尊重系统关闭的通知渠道，避免把未提交的消息标为已提交；防止重复申请待执行的单次检查任务。后台异常记入状态。即时厂商/FCM 推送没有接通。
- 打包：版本 0.8 / versionCode 8，原生界面与 Canvas，无 WebView；结构检查新增源码文件集合核对。

## 验证

本地运行 `bash tests/run-domain.sh`：指标/时间语义 3,860 项、ETF 历史 21 项、HTTP 取消和响应限制 14 项。模拟器新增双指释放、单击详情、坏缓存回退、完整披露校验和请求收盘边界检查；浅色、深色、1.3 倍字体验证由当前提交的 GitHub Actions 执行。运行结果以对应 artifact 与回执为准，未执行部分不得标为通过。

没有更新或发布研报内容，没有更改指标公式。未连接用户手机，OriginOS 真机耗电、长期后台与即时云推送仍未验证。

## 安装

Android 8.0+，包名 com.tide.journal。源码未含原版私有签名，本次为新 CI 测试签名。旧版签名不同会发生安装冲突；需要原签名密钥才能保留数据并直接覆盖升级。不要将签名密钥提交到公开仓库。
